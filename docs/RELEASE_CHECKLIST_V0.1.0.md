## 4. 最終検証

原則として、公開予定コミットのクリーンなcheckoutで実施する。

```powershell
cmd.exe /d /c "mise exec -- npm test"
cmd.exe /d /c "mise exec -- npm run test:coverage"
cmd.exe /d /c "mise exec -- npm run test:e2e"
cmd.exe /d /c "mise exec -- npm run dist"
```

- [ ] unit/integration testが全件成功する。
- [ ] coverage testが全件成功し、所定の閾値を満たす。
- [ ] E2Eが全件成功する。
- [ ] distコマンドが成功し、期待するZIPが1つ生成される。
- [ ] 圧縮ツールを意図的に利用不能または失敗させた場合、distが非0で終了する。
- [ ] ZIPを一時ディレクトリへ展開できる。
- [ ] 展開後のファイル一覧・件数・SHA-256が、ステージング内容およびmanifestと一致する。
- [ ] クリーンなブラウザープロファイルで、起動・保存・再読込・エクスポート・インポートを通しで確認する。
- [ ] インポートボタンを連打しても、利用者の1回の意図につき処理が1回だけ実行される。
- [ ] 時計巻き戻り条件で作成したエクスポートを、同じバージョンへ再インポートできる。
- [ ] 外部通信監視を最初のページ遷移前から有効にし、意図しない外部通信がないことを確認する。
- [ ] 1024px、1280px、1440px幅で主要画面の表示崩れを確認し、証跡を保存する。
- [ ] 正式サポート対象として明記する各OS・ブラウザーで必要な確認を終える。
