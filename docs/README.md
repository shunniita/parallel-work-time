# 開発・公開資料

このフォルダーには、現在の仕様と公開判断に使う文書だけを置いています。
アプリの使い方は、配布ZIPに入っている「取扱説明書.pdf」または[利用者向け説明書](../manual/README.md)をご覧ください。

## 現在参照する文書

- [仕様書](同時並行作業時間計測支援ツール_仕様書.md): 機能、データ、画面、受入条件など、アプリの現行仕様をまとめています。
- [受入条件・受入試験の対応表](ACCEPTANCE_TRACE.md): 仕様書の受入条件と自動試験の対応を確認できます。
- [v0.1.0 公開チェックリスト](RELEASE_CHECKLIST_V0.1.0.md): 公開前の確認結果と、公開時に残っている作業を記録しています。

## 過去の設計・レビュー記録

開発途中の設計メモやレビュー記録は、現在の資料と区別するため、このフォルダーから除いています。必要な場合はGitの履歴から確認できます。
