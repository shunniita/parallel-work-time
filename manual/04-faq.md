# トラブルとFAQ

対象バージョン: v0.1.0 ｜ [説明書の目次へ](README.md)

## 起動できない・表示がおかしい

### 開いても何も表示されない／「起動できませんでした」と出る

- `index.html` をダブルクリックして `file://` で開いていませんか。本ツールはHTTPまたはHTTPSで配信して使います（[インストール手順](01-getting-started.md#3-インストール)）。
- プライベートウィンドウ（シークレットモード）では、ブラウザーを閉じたときに保存データが消える場合があります。通常のウィンドウで開いてください。
- ブラウザーが対応外の可能性があります。Chrome・Edge・Firefox の最新版をお使いください。

### 「サンプルテンプレートを読み込めませんでした」と出る

配布物の `data/` フォルダーが欠けているか、配信サーバーがJSONを返せていません。テンプレートは画面から手動で登録できるので、そのまま使うこともできます。展開し直す場合は、フォルダー構成を変えずに配信してください。

## データが消えた・見えない

### データが消えたように見える

データは「端末 × ブラウザー × ブラウザープロファイル × 配信元URL」の組ごとに別々に保存されます。次のどれかに心当たりがないか確認してください。

- 別のPC・別のブラウザー・別のプロファイルで開いた
- 配信元のURL（ホスト名・ポート・プロトコル）が変わった（例: `http://127.0.0.1:8080` → `http://localhost:8080` も別扱いです）
- ブラウザーのサイトデータ（Cookieとサイトデータ）を削除した

元の組み合わせで開き直せばデータは見えます。組み合わせを変えたい場合は、元の環境でJSONエクスポートし、新しい環境でインポートしてください。

### 本当に消えてしまった場合

エクスポートしたJSONがあれば、設定・バックアップ画面のインポートで復元できます。**バックアップが無い場合、復元手段はありません。** 定期的なエクスポートを習慣にしてください。

### ツールを更新したらデータが見えなくなった

まず、更新前と同じURLを開いているか確認してください。ホスト名・ポート・HTTP/HTTPSのどれかが変わると別の保存領域になります。URLが同じでも起動できない場合は、更新前に保存したJSONと旧版の配布ファイルを消さずに保ち、無理にJSONを編集せず、リリースノートの移行案内を確認してください。

## 保存に失敗する

画面下部に「保存に失敗しました」と出た場合、表示される案内に従ってください。

| 表示 | 対処 |
| ---- | ---- |
| 保存領域が不足しています | JSONへエクスポートして控えを取り、アーカイブの完全削除などで不要なデータを減らす |
| ブラウザの保存領域を利用できません | プライベートウィンドウを避ける。ブラウザーの設定でサイトデータの保存を許可する |
| 入力内容に不備があるため保存できません | 画面に出る場所つきのエラーを直して再実行する |

保存に失敗した操作は記録されていません。エラーを解消してからやり直してください。

## 警告領域の見かた

| 警告 | 意味と対処 |
| ---- | ---------- |
| 未終了の区間 N件 | 終了していない区間の一覧。終了し忘れなら、行のリンクから作業項目を開いて「終了」する。日時は後から修正できる |
| しきい値超過 | 開始からの経過が設定値（既定12時間）を超えた未終了区間。終了し忘れの可能性が高い |
| 同じデータを別のタブでも開いています | 本ツールは同時編集に対応しません。片方のタブを閉じる。同時に操作すると後から保存した内容が残ります |
| 画面の処理でエラーが発生しました | 再読み込みする。続く場合は、設定画面からJSONへ退避したうえで環境（ブラウザー版数など）を確認する |

## インポートが拒否される

インポートは取り込む前に内容を検証し、問題があると場所つきの理由を表示して**一切変更せずに**中止します。

- **schemaVersion が一致しない**: 別の版のツールが書いたファイルは取り込めません。画面下部の `schemaVersion` と、ファイル内の `schemaVersion` が同じであることを確認してください。
- **形式の崩れ**: JSONとして読めない、必須項目が欠けている、日時の形式が違う、などはエラー箇所が表示されます。手で編集したファイルはこの検証に通らないことがあります。
- **上限超過**: 取り込みには次の上限があります。通常の利用で作られたファイルが超えることはありません。

| 対象 | 上限 |
| ---- | ---- |
| ファイルサイズ | 64MB |
| 1種類あたりの件数 | 100,000件 |
| 文字列の長さ | 1,000文字（変更履歴の要約は10,000文字） |
| 1区間の参加者数 | 200名 |
| 数量 | 1,000,000 |
| 作業項目・実施回の合計工数 | 10^12秒 |

インポートの対象は、**本ツールがエクスポートした、利用者本人が管理するJSON**です。出所の分からないファイルは取り込まないでください。

## 知っておくと良い仕様

### 記録・計算

- 工数は「経過時間 × 参加人数」。休憩は0分。直接入力は人数を掛けない総工数として扱われます。
- 転記値は作業項目の合計秒を分へ切り上げた値です。切り上げは一度だけで、区間ごとには丸めません。
- 日をまたぐ区間も正しく計算されます（記録はオフセット付きの日時で保存されます）。
- 参加者名の表記ゆれ（「甲」と「甲 太郎」など）は警告されません。同一人物の名寄せは利用者の判断です。

### 状態と編集

- 転記済み・アーカイブの実施回は閲覧のみです。直すには「転記済みを取り消す」（理由必須）で戻します。
- 削除・状態の後退には理由の入力が必須で、変更履歴としてエクスポートJSONに残ります（履歴の閲覧画面はありません）。
- テンプレートを改訂しても、作成済みの実施回は変わりません。

### 性能の目安

案件20件・実施回100件・作業区間2,000件程度までの規模で支障なく動くことを目標とし、実測で確認しています。これを超える規模の保証はありません。

### セキュリティ

- アプリは配信元以外の外部サービスへ通信せず、作業データを送信しません。静的ファイルを表示するための通常のHTTP通信は配信元との間で発生します。
- 保存内容もエクスポートJSONも平文です。同じ端末・プロファイルを使える人は内容を読めます。機微な情報は入力せず、共有端末では使用後にJSONへ退避してサイトデータを削除してください。

## 制限事項（初版）

- 複数利用者の同時編集、複数端末間の同期はできません。多重タブは警告のみで、後勝ちで保存されます。
- 作業者マスターはありません（参加者名は自由入力）。
- 旧版テンプレートの閲覧画面、変更履歴の閲覧画面はありません。
- スマートフォンには最適化していません。
