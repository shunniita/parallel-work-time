# はじめに — 導入と初回起動

対象バージョン: v0.1.0 ｜ [説明書の目次へ](README.md)

## 1. このツールでできること

同時並行作業時間計測支援ツールは、複数の案件・作業項目・参加者が同時並行で動く現場の工数を、ブラウザだけで記録・集計するツールです。

一般的な時間計測ツールは「一人が一つの作業を順番に進める」ことを前提としがちですが、実際の現場では次のような状況が起こります。

- 複数の案件が同時に進行する
- 一つの案件に複数の作業項目がある
- 複数人が同じ作業項目へ同時に参加し、途中で人が増減する
- 作業と休憩を何度も繰り返す
- その場で時刻を記録できず、後から工数だけを足したい
- 同じ案件を何回かに分けて実施する

本ツールはこれらを一つの画面で記録し、最終的に「どの実施回の、どの作業項目に、合計何分掛かったか」を確認して、外部の記録システムへ転記する値を出せるようにします。

### できないこと（初版の範囲外）

- 複数利用者による同時編集、複数端末間の自動同期
- サーバーや外部サービスとの通信（データはすべて手元のブラウザ内に保存されます）
- 認証・権限管理、勤怠・給与・請求・法定帳票への直接利用
- 外部システムへの自動入力（転記はコピーした値を手作業で貼り付けます）
- スマートフォン向けの画面

## 2. 動作環境

| 区分 | 対応範囲 |
| ---- | -------- |
| OS | Windows 11 |
| ブラウザー | Chrome、Edge、Firefox の各最新版 |
| 配信方式 | HTTPまたはHTTPSによる静的ファイル配信 |
| 必要な機能 | JavaScript、IndexedDB、BroadcastChannel |
| 画面幅 | 1024px以上（1280px以上を推奨） |

- macOS・Linuxは公式の対応対象ではありません（動作する可能性はありますが、確認していません）。
- `index.html` をダブルクリックして `file://` で直接開く方式は動作しません。必ずHTTPで配信してください（次章）。

## 3. インストール

本ツールはインストーラーを持ちません。配布ZIPを展開し、静的なHTTPサーバーで配信するだけで動きます。

### 手順

1. 配布ZIP（`parallel-work-time.zip`）を任意の場所へ展開します。`parallel-work-time` フォルダーができます。
2. 展開したフォルダーを、静的ファイルを配信できるHTTPサーバーへ配置します。
   - 社内のWebサーバーの公開ディレクトリへ置く
   - 手元のPCで簡易サーバーを立てる（例: Pythonが入っていれば、展開先フォルダーで `python -m http.server 8080`）
3. ブラウザーで配信先のURL（例: `http://127.0.0.1:8080/`）を開きます。

サーバー側のプログラムやデータベースは不要です。ツールは外部と一切通信しません。

> **注意**: 配信元URLを後から変えると、保存済みのデータは新しいURLからは見えません（ブラウザーがURLごとにデータを分けて保存するため）。運用を始める前に配信場所を決めてください。詳しくは[FAQ「データが消えた・見えない」](04-faq.md#データが消えたように見える)。

## 4. 初回起動

初めて開くと、架空のサンプルテンプレート3種が自動で投入され、作業テンプレート画面から始まります。

- サンプル（対象種別A／標準 など）はそのまま試し打ちに使えます。不要なら参考にして自分の業務のテンプレートを登録してください。
- 案件を1件でも登録すると、次回からは案件・実施回画面から始まります。

最初の一巡（テンプレート→案件→実施回→記録→集計）は[操作ガイド](02-guide.md)の順に進めてください。

## 5. データの保存場所と注意

作業データは、ブラウザーの中（IndexedDB）へ保存されます。操作のたびに自動保存され、画面下部に「保存しました」と出ます。

次の点にだけ注意してください。

- **保存先は「端末×ブラウザー×プロファイル×配信元URL」ごとに別**です。別のPCやブラウザーからは見えません。
- **ブラウザーのサイトデータを削除すると、記録も消えます。**
- 保存内容は暗号化されません。機微な情報は入力しないでください。
- 定期的に、設定・バックアップ画面から**JSONエクスポート**で控えを取ってください（[操作ガイド9章](02-guide.md#9-バックアップを取る)）。

## 6. 用語

| 用語 | 意味 |
| ---- | ---- |
| 案件ID | 利用者が管理対象へ割り当てる識別子。同一案件IDの下に複数の実施回を持てる |
| 対象種別 | 作業対象の分類。製品、業務種別、イベント種別など |
| バリエーション | 同一対象種別における仕様差。必要な作業項目の組合せを決める |
| 総予定数 | 案件全体で予定される数量 |
| 実施回 | 同一案件を分割して実施する単位。同じ日でも複数作れる |
| 今回数量 | 一つの実施回で扱う数量 |
| 作業項目 | 工数を集計する単位 |
| 作業テンプレート | 対象種別とバリエーションに対応する作業項目の定義 |
| 参加者 | 作業区間へ参加した人。名前は自由入力（作業者マスターは無い） |
| 作業区間 | 開始日時と終了日時を持つ、作業または休憩の時間帯 |
| 直接入力 | 時刻を使わず、工数を直接追加する記録 |
| 工数 | 作業時間×参加人数の合計。内部単位は秒 |
| 転記値 | 外部の記録先へ入力するため、作業項目の合計秒を分単位へ切り上げた値 |
| 外部項目コード | 外部システムや帳票上の項目と対応付ける任意のコード |
| アーカイブ | 転記済みの実施回を、通常一覧から分離して保管する状態 |
