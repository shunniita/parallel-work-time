# 操作ガイド — 業務の流れに沿った手順

対象バージョン: v0.1.0 ｜ [説明書の目次へ](README.md)

日々の業務は次の流れで進みます。この章はこの順番どおりに書いてあります。

```text
1 テンプレートを用意する（最初の一度だけ）
2 案件を登録する
3 実施回を作る
4 作業時間を記録する（開始・休憩・再開・終了・参加者変更）
5 計測漏れを直接入力で足す
6 記録を修正する
7 集計して転記する
8 アーカイブして、保持期間が過ぎたら削除する
9 バックアップを取る（随時）
```

## 1. テンプレートを用意する

作業テンプレートは「この対象種別・このバリエーションなら、この作業項目一式」という定義です。実施回を作るとき、ここから作業項目が自動生成されます。

![作業テンプレート画面](images/screen-templates.png)

1. ヘッダーの「テンプレート」を開く。
2. 「新規テンプレート」を押し、対象種別とバリエーションを入力して「登録」。
3. 一覧から登録したテンプレートを選び、「作業項目を追加」で作業項目を足す。名称・外部項目コード・表示順・有効を設定する。
   - **外部項目コード**は転記先の項目と対応付ける任意のコードです。未設定でも使えますが、その項目の転記値はコピーへ含められません。
4. 「改訂して保存」で確定する。保存のたびに版が上がります。

**改訂しても、作成済みの実施回は変わりません。** 実施回は作成時点のテンプレート内容を固定して持つため、過去の記録が後から変わることはありません。改訂後に作った実施回から新しい内容になります。

対象種別とバリエーションも、編集領域の入力欄から直せます。表記の誤りを直したいときに使ってください。ほかのテンプレートと同じ組み合わせにはできません。

### 似たテンプレートを作る

一覧の「複製」を押すと、そのテンプレートの作業項目をそのまま持った新規登録フォームが開きます。対象種別かバリエーションのどちらかを変えて「登録」してください。同じ組み合わせのままでは登録できません。

複製したテンプレートは元とは別のものとして扱われます。あとから元を改訂しても、複製先には反映されません。

### 使わなくなったテンプレート

一覧の「アーカイブ」を押すと、そのテンプレートは一覧と実施回の作成候補から外れます。版は上がらず、記録も残ります。

アーカイブしたものは「アーカイブ済み」の表に並びます。「戻す」でいつでも一覧へ復帰できます。ただし、アーカイブ中に同じ対象種別・バリエーションで別のテンプレートを作っていると戻せません。

「削除」を押すと、確認のうえで記録ごと消えます。**この操作は取り消せません。** すでに実施回で使ったテンプレートは削除できないため、その場合はアーカイブのままにしてください。

## 2. 案件を登録する

![案件登録画面](images/screen-project-form.png)

1. 左ツリーの「新規案件」を押す。
2. 案件ID・対象種別・バリエーション・総予定数を入力して「登録」。
   - 対象種別とバリエーションの組で、使うテンプレートが決まります。
   - 総予定数は案件全体の予定数量です。実施回を重ねるごとに累計・残数が自動計算されます。
3. 登録済みの案件IDを入力した場合は、その案件の内容が表示され「この案件へ実施回を追加」から続きの作業へ入れます（同じ案件IDは二重登録できません）。

登録すると案件詳細へ移り、そのまま実施回の追加フォームが開きます。

## 3. 実施回を作る

実施回は「同じ案件の何回目の作業か」を表す単位です。同じ日に複数作ることもできます。

![案件詳細画面](images/screen-project.png)

1. 案件詳細で「実施回を追加」を押す（案件登録直後は自動で開いています）。
2. 作業日と今回数量を入力する。
3. 生成される作業項目の一覧が出るので、今回使わない項目はチェックを外す。
4. 「作成」を押す。
   - 累計が総予定数を超える場合は確認が出ます。「確認して続行」で超過のまま保存できます。

## 4. 作業時間を記録する

実施回詳細の各行にあるボタンで、その場の出来事をそのまま記録します。

![実施回詳細画面](images/screen-run.png)

| ボタン | いつ押すか | 何が起きるか |
| ------ | ---------- | ------------ |
| 開始 | 作業を始めたとき | 作業区間が開き、状態が「作業中」になる |
| 休憩 | 手を止めたとき | 作業区間が閉じ、休憩区間が開く。参加者は引き継がれる |
| 再開 | 休憩から戻ったとき | 休憩区間が閉じ、選択した参加者で作業区間が開く |
| 終了 | 作業を終えたとき | 進行中の区間が閉じ、状態が「完了」になる |
| 参加者変更 | 人が増減したとき | 進行中の区間がその時刻で分割され、新しい顔ぶれで続きが開く |

- 日時は現在時刻が初期値です。確定前に修正できるので、少し前の出来事を後から記録してもかまいません。
- 参加者は名前を入力して追加します。過去に入力した名前が候補に出ます。作業区間には1名以上が必要です（休憩は0名でも可）。
- 複数の作業項目を同時に「作業中」にできます。項目ごとに独立して記録してください。
- 「完了」は最終状態ではありません。もう一度「開始」すれば作業中へ戻ります。
- 状態に合わないボタンは表示されません（例: 作業中でない項目に「休憩」は出ません）。

**工数の計算**: 作業区間の工数 ＝ 経過時間 × 参加人数です。2人で30分作業すれば60分と数えます。休憩区間は0分です。

## 5. 計測漏れを直接入力で足す

時刻を記録し損ねた分は、工数を数字で直接足せます。

1. 実施回詳細で作業項目名を押し、作業項目詳細を開く。
2. 「直接入力」を押し、追加工数（分・秒）・参加者・備考を入力して保存する。
   - **備考は必須**です。時刻の裏づけが無い数字なので、後から根拠をたどれるようにします。
   - **直接入力の値は人数を掛けません。** 2人で20分ずつ作業した分を足すなら「40分」と入力してください（参加者欄は誰の分かの控えで、計算には使いません）。

同じ参加者・同じ工数の直接入力が既にあると、二重登録の可能性として警告が出ます（保存はできます）。

## 6. 記録を修正する

作業項目詳細で修正します。

![作業項目詳細画面](images/screen-task.png)

- **区間の修正・削除**: 「履歴編集」を押すと、区間履歴の各行に「編集」「削除」が出ます。削除には理由の入力が必須で、変更履歴に残ります。
- **区間の後追加**: 「区間追加」で、開始・終了日時を指定した区間を後から足せます（終了日時は必須）。
- **直接入力の修正・削除**: 直接入力の表の「操作」列から行います。削除には理由が必要です。
- 終了日時は開始日時以降であること、同一時刻（0秒の区間）は許されます。時間帯が重なる区間は警告が出ますが、別グループの同時並行作業なら正しい記録なのでそのまま保存できます。

転記済み・アーカイブの実施回は閲覧のみです。転記済みは、次章の手順で集計済みへ戻してから修正できます。アーカイブ済みは元の状態へ戻せないため、修正できません。

## 7. 集計して転記する

![集計・転記画面](images/screen-summary.png)

1. 左ツリーで実施回を選び、ヘッダーの「集計・転記」を開く。
2. 作業項目ごとの転記値（合計秒を分へ切り上げた値）を確認する。
   - 切り上げは作業項目の合計に対して一度だけ行われます。区間ごとには丸めません。
   - 未終了の区間がある項目は「未確定」と出ます。先に終了してください。
3. 「集計済みにする」を押す。誤りに気づいたら「作業中へ戻す」で戻れます。
4. 「転記値をコピー」でタブ区切りのテキストをコピーし、外部の記録先へ貼り付ける。
   - 並びは画面の表示順に関わらず、常に外部項目コード順です。
   - 外部項目コード未設定の項目はコピーへ含まれず、その旨が表示されます。
   - 右端のチェックは消し込みの目印です。保存されないため、再読み込みで消えます。
5. 転記先への入力を終えたら「実施回を転記済みにする」を押す。
   - 転記済みの実施回は編集できなくなります。誤りに気づいたら「転記済み状態を解除する」（理由必須）で集計済みへ戻します。

> **貼り付け時の注意**: `=` `+` `-` `@` で始まる外部項目コードは、表計算ソフトが数式として解釈することがあります。「テキストとして貼り付け」を使うか、コードの先頭にこれらの文字を使わないでください。

## 8. アーカイブして、保持期間が過ぎたら削除する

![アーカイブ画面](images/screen-archive.png)

1. 転記済みの実施回は、集計・転記画面の「アーカイブへ移す」で通常一覧から分離できます。自動では移りません。
2. アーカイブ画面で、アーカイブ済みの実施回を案件ごとに一覧できます。
3. アーカイブから保持期間（既定30日、設定で変更可）が過ぎると「削除候補」になり、「完全削除」を押せるようになります。自動では削除されません。
4. 削除は2段階の確認があります。
   1. 削除の理由を入力する（変更履歴に残ります）。
   2. 「削除する前にJSONへ退避しますか」— **「退避してから削除する」を推奨します。** 完全削除は取り消せません。
5. 配下の実施回がすべて削除候補（または0件）の案件は「案件ごと削除」できます。

## 9. バックアップを取る

![設定・バックアップ画面](images/screen-settings.png)

データはブラウザーの中にしかありません。ブラウザーのサイトデータ削除やプロファイル初期化で消えるため、**定期的なエクスポートを強く推奨します。**

おすすめの運用:

- 作業日の終了時、まとまった入力の後、完全削除の前、ツール更新の前にエクスポートする
- JSONはブラウザープロファイルとは別のフォルダーへ保存し、直近数回分を上書きせず残す
- 自動で付く日時入りのファイル名（例: `parallel-work-time_20260810-180000.json`）を変えずに保管する
- ダウンロード後にファイルが存在し、サイズが0バイトでないことを確認する

### エクスポート

設定・バックアップ画面の「JSONをエクスポート」で、設定・テンプレート・案件・実施回・変更履歴のすべてが1つのJSONファイルとしてダウンロードされます。画面に最終エクスポート日時が表示されます。

### インポート（復元）

![インポートの確認](images/screen-import-confirm.png)

1. 「取り込むJSONファイル」でエクスポートしたファイルを選ぶ。内容が検証され、問題があれば場所つきで理由が表示されます。
2. 確認が出ます。**インポートは差分マージではなく全置換です。** 現在のデータはすべて置き換わります。
   - 「現在のデータを退避して取り込む」— 推奨。今のデータを先にダウンロードしてから置き換えます。
   - 「退避せずに進む」— さらに確認があります。取り消せません。
3. 取り込めるのは、本ツールがエクスポートした同じスキーマ版のJSONだけです。画面下部の `schemaVersion` が一致しないファイルは拒否されます。JSONを手で編集せず、元のファイルをそのまま選んでください。

### 設定

| 項目 | 意味 | 既定値 |
| ---- | ---- | ------ |
| 保持期間（日） | アーカイブ後、完全削除できるようになるまでの日数 | 30 |
| 未終了しきい値（時間） | 未終了の区間を警告領域で「超過」と強調するまでの時間 | 12 |
