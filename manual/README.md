# 同時並行作業時間計測支援ツール 説明書

対象バージョン: v0.1.0

複数の案件・作業項目・参加者が同時並行で動く現場の工数を、ブラウザだけで記録・集計するツールの利用者向け説明書です。

## 読み方

| 冊 | 内容 | こんなときに |
| -- | ---- | ------------ |
| [1. はじめに](01-getting-started.md) | ツールの概要、動作環境、インストール、初回起動、用語 | 導入するとき。最初に読む |
| [2. 操作ガイド](02-guide.md) | テンプレート登録から集計・転記・削除・バックアップまで、業務の流れ順の手順 | 使い方を覚えるとき。日々の操作の確認 |
| [3. 画面リファレンス](03-screens.md) | 全画面のボタン・項目の意味 | 画面の項目が分からないとき |
| [4. トラブルとFAQ](04-faq.md) | 起動しない・データが見えない・警告の意味・インポートの拒否理由・制限事項 | 困ったとき |

初めての方は 1 → 2 の順にどうぞ。2の操作ガイドは、実際の業務の流れ（テンプレート → 案件 → 実施回 → 記録 → 集計 → 転記 → アーカイブ）と同じ順に並んでいます。

## 最重要の注意だけ先に

- データは**お使いのブラウザーの中**に保存されます。ブラウザーのサイトデータを削除すると記録も消えます。
- **定期的に「設定・バックアップ」画面からJSONエクスポートで控えを取ってください。** JSONは、本ツールが提供する唯一の復元手段です。
- `index.html` を直接開く方式（`file://`）では動きません。手元のWindows 11 PCでは、ZIPを展開して `start-local.cmd` をダブルクリックしてください。Pythonのインストールは不要です（[インストール](01-getting-started.md#3-インストール)）。
- 既定のポートは `4173` です。必要な場合だけ `local-settings.txt` で変更できますが、URLが変わると以前のデータが見えなくなるため、先にJSONバックアップを取ってください。

> 画面写真は説明用の架空データです。ブラウザーや画面幅により、ボタンの位置やファイル選択欄の表示は少し異なることがあります。
