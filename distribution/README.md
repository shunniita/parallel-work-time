# 同時並行作業時間計測支援ツール

複数の案件・作業項目・参加者が同時並行で動くときの工数を、ブラウザーで記録・集計するツールです。

## まずはここだけ

1. ダウンロードしたZIPを右クリックし、**「すべて展開」**を選びます。
2. 展開したフォルダーの `start-local.cmd` をダブルクリックします。
3. 黒い画面を閉じずに、開いたブラウザーで操作します。

Python、Node.js、管理者権限の追加は不要です。`index.html` を直接開いても動作しません。

詳しい導入手順は[説明書「はじめに」](manual/01-getting-started.md)を参照してください。起動しない場合は[トラブルとFAQ](manual/04-faq.md)を確認してください。

## データを失わないために

- 作業データは、使用中のPCにある**ブラウザーの中**へ保存されます。
- PC、ブラウザー、ブラウザープロファイル、または起動URLが変わると、以前のデータは表示されません。
- ブラウザーのサイトデータを削除すると、保存した作業データも削除されます。
- **「設定・バックアップ」画面から定期的にJSONをエクスポートしてください。** JSONが本ツールの復元手段です。
- ZIPを新版へ入れ替える前と、`local-settings.txt` のポート番号を変更する前にも、JSONを保存してください。
- 保存内容とJSONは暗号化されません。個人情報や機微な情報は入力せず、JSONの保管場所と共有範囲を利用者が管理してください。

インポートには、本ツール自身が出力したJSONか、利用者本人が内容を把握しているJSONだけを使用してください。

## ポート番号を変更する場合

通常は変更不要です。既定では `http://127.0.0.1:4173/` を使用します。

変更が必要な場合は、起動前に `local-settings.txt` を開き、`port=4173` の数字だけを `1024`～`65535` の範囲で変更します。URLが変わると別の保存場所として扱われるため、先にJSONをエクスポートしてください。

## 動作環境

- 正式対応: Windows 11
- ブラウザー: Chrome、Edge、Firefoxの各最新版
- 推奨画面幅: 1024px以上

Windows 10は同等に動く想定ですが未確認です。macOS、Linux、WSLは正式な対応対象ではありません。

本ツールはローカルHTTPで画面用ファイルをブラウザーへ渡しますが、入力した作業データを外部サービスへ送信しません。説明書の画面写真と同梱サンプルは、すべて架空のデータです。

## フォルダーについて

普段操作するのは、主に次のファイルとフォルダーです。

```text
start-local.cmd       起動する
local-settings.txt    必要な場合だけポート番号を変更する
README.md             この案内
manual/               詳しい説明書
```

`アプリ内部（変更しないでください）/` の中は、名前の変更・移動・削除をしないでください。起動できなくなる原因になります。
