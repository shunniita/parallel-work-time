# 同時並行作業時間計測支援ツール

複数の案件、作業項目、参加者が同時並行で作業する状況において、項目ごとの工数を記録・集計するためのブラウザアプリケーションです。

作業の開始・終了時刻、休憩時間、参加者数から工数を計算できます。時刻を記録できなかった作業については、工数を直接追加することもできます。

本ツールは現在開発中です。現時点では実運用を想定した安定版ではありません。

## 想定する用途

一般的な時間計測ツールは、一人が一つの作業を順番に進める運用を想定していることがあります。

本ツールは、次のような状況を扱うことを目的としています。

* 複数の案件が同時に進行する
* 一つの案件に複数の作業項目がある
* 複数人が同じ作業項目へ参加する
* 作業中に参加者が増減する
* 作業と休憩を複数回繰り返す
* 一つの案件を複数回に分けて実施する
* 作業終了後に、項目ごとの合計工数を確認したい
* 別の記録システムへ転記する値を算出したい

## 主な機能

初版では、次の機能を実装する予定です。

* 案件IDごとの作業管理
* 同一案件に対する複数の実施回
* 対象種別とバリエーションに応じた作業項目の自動生成
* 複数の作業項目の同時進行
* 作業開始、休憩、再開、終了の記録
* 一つの作業区間への複数参加者の登録
* 工数の直接入力
* 秒単位での工数計算
* 項目別合計工数の分単位への切り上げ
* 未終了区間の警告
* 集計値の転記済み管理
* JSON形式でのバックアップと復元
* 転記済みデータのアーカイブ

詳細は[仕様書](docs/同時並行作業時間計測支援ツール_仕様書.md)を参照してください。

## 工数の計算

作業区間の工数は、経過時間と参加者数から計算します。

```text
作業区間の工数
= 作業区間の経過秒数 × 参加者数
```

休憩区間は工数に含めません。

時刻入力分と直接入力分を秒単位で合計し、外部システムへ転記する値のみ分単位へ切り上げます。

```text
転記値
= ceil（作業項目の合計秒数 ÷ 60）
```

各区間では丸めず、作業項目の合計に対して一度だけ切り上げます。

## 動作環境

初版では、次の環境を主対象とします。

* PC
* Chromium系ブラウザの最新安定版
* HTTPまたはHTTPSによる静的ファイル配信
* JavaScriptおよびIndexedDBが利用可能な環境

`file://`でHTMLファイルを直接開く方式は、動作保証の対象外です。

サーバー側のAPI、データベース、常駐プログラムは使用しません。

## 開発環境

* Git


## データの保存

作業データはブラウザのIndexedDBへ保存します。

IndexedDBのデータは、利用する端末、ブラウザ、ブラウザプロファイル、配信元URLごとに分離されます。

次の場合、データを参照できなくなったり、失ったりする可能性があります。

* 別のPCやブラウザを使用した
* 配信元URLを変更した
* ブラウザのサイトデータを削除した
* ブラウザプロファイルを初期化した

重要なデータは、定期的にJSON形式でエクスポートしてください。

## 公開リポジトリに含めない情報

このリポジトリには、実在する組織や業務に固有の情報を含めません。

次の情報はコミットしないでください。

* 実在する組織名
* 実際の案件ID
* 実際の製品名や業務名
* 実際の作業項目名や外部項目コード
* 参加者の氏名
* 実際の工数記録
* エクスポートした作業データ
* 社内システムの画面や内部仕様
* 認証情報や秘密情報

サンプルデータには、すべて架空の名称を使用します。

## Git管理

Gitで管理する対象は、次のものです。

* プログラム
* 仕様書
* README
* 架空のサンプルデータ
* 初期テンプレート
* テストコード

実際の作業データを含むJSONはGit管理の対象外です。

```gitignore
work-data_*.json
export/
*.local.json
*.private.json
.env
.env.*
```

## 開発方針

* 仕様書に記載された機能を優先する
* 初版では一人の管理者による利用を前提とする
* 複数利用者の同時編集には対応しない
* 外部APIや外部クラウドサービスへデータを送信しない
* 不要な外部ライブラリを導入しない
* 仕様変更は文書へ反映してから実装する
* 実データを使用せず、架空データで試験する

## 注意事項

本ツールは、作業時間の一時的な記録と計算を補助するためのものです。

正式な勤怠管理、給与計算、請求、法定記録、原価管理などへ使用する場合は、利用者自身が計算結果と運用上の要件を確認してください。
